# Getaway

Flask dashboard showing sunny European destinations reachable by direct flight from Ireland. See [README.md](README.md) for architecture and deployment.

## Workflow rule

After making changes in this repo, automatically commit and push to `origin/main` — don't wait to be asked. Use a normal descriptive commit message. If a change is experimental, in-progress, or the user says to hold off, skip the auto-push and say so.
